# Российский IPTV плейлист
Коллекция общедоступных российских IPTV каналов, собранных из разных источников в один плейлист.

## Использование
Скопируйте ссылку на плейлист и вставьте в любой IPTV плеер.

* Основной
  ```
  https://ngrch.github.io/iptv/ru.m3u
  ```
* Музыка и радио
  ```
  https://ngrch.github.io/iptv/music.m3u
  ```
* Мультфильмы
  ```
  https://ngrch.github.io/iptv/cartoons.m3u
  ```

## Поддержка
[![Волна ТВ](https://img.shields.io/itunes/v/6745237104?logo=apple&label=%D0%92%D0%BE%D0%BB%D0%BD%D0%B0%20%D0%A2%D0%92)](https://apps.apple.com/app/id6745237104)

Если у вас есть iPhone или iPad, то лучшая ваша поддержка - скачать приложение "Волна ТВ" и поставить хороший отзыв. Это IPTV плеер, где вы как раз сможете смотреть каналы из этого плейлиста прямо на вашем устройстве.

Для финансовой поддержки используйте ссылку в Sponsor - это очень мотивирует держать плейлист в актуальном состоянии.
